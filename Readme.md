# Spawner Ticket Bot

Fully customizable Discord bot with:
- Spawner Sell/Buy ticket panel (modals + calculation)
- Normal ticket system
- Calculator
- Moderation commands
- Everything configurable by admins

## Setup
1. Install requirements: `pip install -r requirements.txt`
2. Put your bot token in `config.json`
3. Invite bot with Administrator + applications.commands scope
4. Run: `python bot.py`
5. Use `/setup` and configure roles/category
6. Run `/spawnerpanel` to post the panel

## Admin Commands
- `/setup`
- `/setcategory`
- `/setrole`
- `/setlogchannel`
- `/setbuyprice`
- `/config`
- `/spawnerpanel`
